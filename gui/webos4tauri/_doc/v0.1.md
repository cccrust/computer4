# v0.1 — 專案初始化與 Shell 核心

## 目標
初始化 Tauri v2 專案，建立 Shell 核心 UI，實作 App Manager 基本功能，讓系統可以顯示主畫面並列出已安裝 App。

## 範圍 (對應 todo.md Phase 1)

| Item | 說明 |
|------|------|
| 1.1 | Tauri v2 專案初始化 |
| 1.2 | React + Vite + TypeScript + Tailwind 前端 |
| 1.3 | Shell 核心元件：StatusBar, HomeScreen, AppIcon, Dock, AppContainer |
| 1.4 | App Manifest JSON schema 定義 |
| 1.5 | App Manager Rust commands：list_apps, get_app_manifest, install_app, uninstall_app |
| 內建 App 骨架 | 4 個 App 的 manifest + 基本頁面 |

## 驗收標準

- [x] `pnpm tauri dev` 可正常啟動，顯示手機框架主畫面
- [x] StatusBar 顯示時間
- [x] HomeScreen 顯示預設 App Icon 網格
- [x] Dock 顯示常用 App
- [x] 點擊 App Icon 可開啟 AppContainer
- [x] App Manager 可回傳內建 App 清單
- [x] 4 個內建 App 有實際功能
  - [x] File Explorer - 檔案瀏覽、新增資料夾/檔案、刪除、重新命名
  - [x] Terminal - xterm.js 終端機，可執行 bash 命令
  - [x] Editor - 文字編輯器，可開啟/儲存檔案
  - [x] Browser - 網頁瀏覽器，支援網址列、前進、後退
